# Unspoken_Cues_Capstone
## Resort/Event Management Platform

### About the Project

Unspoken Cues is developing a discreet communication ecosystem for resorts, events, and social environments. The larger ecosystem combines wearable visual signals, digital profiles, QR-based interactions, and staff-side management tools to help participants communicate availability, preferences, and boundaries more clearly. 

Our team is developing the staff-side resort/event management platform. The platform is intended to give authorized resort and event staff a centralized way to manage guests, deployments, staff access, QR identities, and other operational information related to the Unspoken Cues experience.

### Technology
The final technology stack is being determined as development progresses. The project is expected to use technologies appropriate for a modern web application, database, and API-based architecture.
Potential technologies include:

- React / Next.js
- Node.js
- PostgreSQL
- Git & Github

- Docker
